# যাকাত ক্যালকুলেটর — অ্যান্ড্রয়েড অ্যাপ

কুরআন ও সুন্নাহর আলোকে সহজে নিজের যাকাত হিসাব করুন — বাংলায়, চাইলে ইংরেজিতে।

**[⬇️ সর্বশেষ APK ডাউনলোড করুন](../../releases/latest)**

## যা যা আছে

- **সম্পদের যাকাত** — ধাপে ধাপে: নগদ ও ব্যাংক, বিকাশ/নগদ/রকেট, সঞ্চয়পত্র-এফডিআর, সোনা-রূপা, ব্যবসা, শেয়ার, ঋণ
- **সোনা-রূপা ভরি-আনা-রতিতে** — ২২, ২১, ১৮ ক্যারেট ও সনাতন; বাজুসের আজকের দাম স্বয়ংক্রিয়ভাবে
- **হানাফি মাযহাবের নিসাবের নিয়ম** — শুধু সোনা থাকলে ৭.৫ ভরি, মিশ্র সম্পদে ৫২.৫ ভরি রূপার দাম
- **ফসলের যাকাত (উশর)**, **গবাদি পশুর যাকাত**, **ফিতরা হিসাব** (২০২৬ সালের হার)
- **কুরআন-হাদিসে যাকাত** — আরবি মূল পাঠ, বাংলা ও ইংরেজি অর্থ, হাদিসের মান (সহীহ/হাসান/দুর্বল)সহ
- **যাকাত কারা পাবেন** — সূরা তাওবার ৮টি খাত, কাদের দেওয়া যাবে না
- **প্রশ্ন ও উত্তর** — গহনা, প্রভিডেন্ট ফান্ড, সঞ্চয়পত্র, প্লট-ফ্ল্যাট, শেয়ার, ঋণ ইত্যাদি
- ইন্টারনেট ছাড়াই চলে; আপনার তথ্য শুধু আপনার ফোনে থাকে

## ইনস্টল করার নিয়ম

1. ওপরের লিংক থেকে `.apk` ফাইলটি ডাউনলোড করুন।
2. ফোনে ফাইলটি খুলুন। "অজানা উৎস থেকে ইনস্টল" চাইলে অনুমতি দিন।
3. অ্যান্ড্রয়েড ৮.০ বা তার পরের সংস্করণ লাগবে।

> আগের (ওয়েবভিউ) সংস্করণ ফোনে থাকলে নতুনটি ইনস্টলের আগে পুরোনোটি আনইনস্টল করুন।
